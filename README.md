# Computação Quântica – Simulação de um circuito de Bell

Trabalho de Arquitetura e Organização de Computadores (Grupo 4).

## O que faz
Simula um circuito quântico de 2 qubits (Hadamard + CNOT + medição) que gera o estado de Bell (|00> + |11>)/√2.

## Como executar
```bash
pip install numpy
python simulador_quantico.py
```
Versão opcional com Qiskit:
```bash
pip install qiskit qiskit-aer
python bell_qiskit.py
```
